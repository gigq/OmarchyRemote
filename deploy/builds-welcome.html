A home for your builds.

Your dashboard is ready. Give your coding agent the publishing skill to add your first app update, release notes, and install link.

Get the agent skill ↓
  1. Add the skill. Save it as omarchy-builds/SKILL.md in your agent’s skills folder.
  2. Ask your agent. “Use omarchy-builds to publish my latest signed build to this host.”
  3. Come back for updates. Your builds and install links will appear here automatically.

Works with Codex and Claude Code. No dashboard setup needed.
