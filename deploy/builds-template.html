Install from anywhere

Connect Tailscale, open this page in Safari, then choose Install on device and accept the iOS prompt. Return to the Home Screen to follow installation.

These development builds require a registered device and Developer Mode. If iOS declines installation, keep the current app installed and use the IPA download for installation from a Mac. Downloading the IPA alone does not install it.

Publish with your coding agent

This dashboard is included with every Omarchy Remote host. Add the publishing skill to your agent, then ask it to publish a validated build with release notes.

Download the agent skill. Save it as omarchy-builds/SKILL.md in your agent’s skills directory (for example, ~/.codex/skills or ~/.claude/skills).

Private to your Tailscale network. Builds are retained until removed.
