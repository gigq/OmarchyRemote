Hyprland-touch · integrated prototype
Everything chosen so far in one phone: the 7a shell (top bar, colored workspaces, edge bars, gesture map), the 2a keyboard with SUPER binds and the terminal layer, the 6a launcher, files as 8a, settings as 9c, the agent manager as 10a with the 11a pane.
Gestures
Left / right edge: previous / next workspace. Bottom-left up: keyboard. Bottom-middle up: expo. Bottom-right up: keyboard with SUPER held. Top-left down: notifications. Top-middle down: launcher. Top-right down: quick settings. On an agent pane, swipe anywhere on the pane to move between panes.
What is live
Workspaces open when launched (from home tiles, the launcher, or SUPER + a letter) and get their color, pill, and edge bar. Type in the launcher with the on-screen keyboard; ⏎ opens the first match. SUPER + q closes the current workspace. Wi‑Fi toggles in settings or quick settings switch the status bar to 5G. In files, tap rows to select. In herd, tap an agent to open its pane and answer a blocked agent with the buttons; the herd list and the notification update.
